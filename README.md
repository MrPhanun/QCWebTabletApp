# QC Dept App

`npm run dev` (development) or `npm start` (production). Settings are in `config/<env>.json`, and the DB password goes in `.env.<env>` (see `.env.example`).

## Where things are

```
server.js                  Entry point: starts the server, routes each URL to a handler, checks permissions
server/
  config.js                Loads config/<env>.json + .env.<env>
  db.js                    SQL Server connection pool
  http.js                  sendJson / readJson helpers
  session.js               Login sessions (cookie "sid")
  permissions.js           Permission keys, default rules, which API needs which permission
  static.js                Serves files from public/
  excel-builder.js         Fills the Excel templates in templates/
  routes/
    auth.js                /api/login, /api/logout, /api/me
    sampling.js            /api/sampling          Master Data › OQC Inspection
    spec.js                /api/spec              Master Data › SPEC (keyed by Part No)
    oqc.js                 /api/oqc/records, /api/oqc/spec    Reports › OQC Data Information
    excel.js               /api/excel/oqc, /api/excel/spec    Excel download
    users.js               /api/users, /api/user/name         Administration › User Management
    permissions.js         /api/permissions       Administration › Roles & Permissions

public/                    Everything the browser loads
  login.html, menu.html, home.html, favicon.ico
  css/login.css
  css/menu/                base → forms → screens → dialog → shell (loaded in that order)
  js/login.js
  js/menu/                 Plain scripts sharing one global scope, loaded in the order listed in menu.html:
    icons.js               SVG icons (svg(), ico())
    i18n.js                Khmer / English text (STR), t(), server message translations
    common.js              esc(), dialogs, can(), api(), downloadExcel()
    tree.js                Sidebar menu (MENU), navigation, search, mobile drawer
    screens/<name>.js      One file per screen: sampling, spec, users, roles, oqc (+ oqc-sheet.js shared layout)
    app.js                 SCREENS map, language switch, startup (loads the signed-in user)
  js/spec-print.js         Generated by tools/xlsx_to_print_template.py

templates/                 Excel templates (OQC Data.xlsx, Spec.xlsx)
db/                        SQL scripts for the tables
```

To add a screen: create `public/js/menu/screens/<name>.js` with a `render<Name>(panel)` function, add its `<script>` tag to `menu.html` before `app.js`, add it to `MENU` (tree.js) and `SCREENS` (app.js), and add its API route file to `server/routes/` plus the line in `server.js` and `permFor`.
